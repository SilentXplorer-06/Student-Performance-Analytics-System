## 2. Objective

I made this project to practise using Python to review student marks. It calculates totals and averages, assigns grades, checks pass or fail, and summarizes the class results. This makes it easier to review the marks than calculating everything by hand.

## 3. Technologies Used

- **Python** for the program, conditions, loops, and functions.
- **Pandas** to read the CSV file and organize student records in a DataFrame.
- **NumPy** for numerical calculations, pass/fail checks, counts, and averages.
- **CSV files** to store the sample data and calculated results.
- **VS Code** to edit and run the program.

## 4. Dataset Description

The file `students.csv` contains 20 fictional student records. Each row includes a student ID, name, department, marks in Python, Mathematics, Data Analysis, and AI Fundamentals, plus attendance percentage. The records are sample data created for this project, not real student results.

## 5. How I Implemented It

First, I used Pandas to load `students.csv`. Pandas calculates each student's total and average marks. I made a function called `calculate_grade()` that returns a grade based on the student's average.

I used NumPy to check the marks in every subject. A student gets a Pass result only when they have at least 35 marks in all four subjects. NumPy is also used to count pass and fail results and calculate the class average, highest and lowest averages, and each subject's average. A loop prints the subject averages, and Pandas sorts the results to show the top three students. At the end, the program saves the calculated information in `student_results.csv`.

## 6. Main Features

- Reads student records from a CSV file using Pandas.
- Calculates total and average marks for each student.
- Assigns grades using a defined grading scale.
- Uses NumPy to check pass/fail status.
- Shows pass and fail counts, class average, and highest and lowest student averages.
- Calculates subject-wise averages and lists the top three students.
- Saves the processed data to a CSV file.
